# BeFirst com a cas TFG/TFM

Simulació local separada de les dades de BF i dels altres esborranys acadèmics.

- TFG: col·lecció de 12 peces úniques, identitat 90s futurista, disseny/prototip i prova exploratòria.
- TFM: pregunta de recerca sobre viabilitat 1-of-1, plataforma curada, hipòtesis, metodologia i escenaris de cost.
- Proposta inicial editable i encara no presentada; cap dada comercial inventada.
- Perfil estudiant/docent simulat, versions immutables, retorn explicat i esborranys locals. Exportació JSON i bloqueig de sobreescriptura en conflicte/corrupció.
- Fites i criteris orientatius; tutor i universitat pendents. Cap nota, matrícula, càrrega de fitxers o invitació real.
- Rutes #befirst-tfg / #befirst-tfm des del Campus i guia del pilot. La navegació global permet tornar a les quatre esferes.

Persistència: quelcom.befirst-academic.v1. Cap consulta o escriptura a bf-be-first-dev ni a la base de Quelcom. Cap importació automàtica de documents comercials.

Proves de reload, revisió docent, versions independents, corrupció i impossibilitat de revisar com a estudiant. QA visual pendent.
