# Campus Studio — primera iteració visual

Publicada al Site com a versió 52. Entrada editorial diferenciada per estudiant/docent,
targetes de Coworking/Biblioteca/Universitats, superfícies de treball amb millor contrast,
formularis més llegibles, focus visible i interaccions amb llum i elevació discreta.
BeFirst TFG/TFM incorpora portada tipogràfica, orientació del següent pas segons el perfil,
comptadors de versions/retorns a partir de dades locals i mapa numerat de sis etapes.
Els comptadors no són percentatges de progrés acadèmic. Les etapes són propostes.

Es conserven rutes, formularis, persistència i permisos de la demo. No modifica la
portada Quelcom ni la pantalla de les quatre esferes. Estils limitats a uc-shell.
La variant mòbil usa una columna i controls grans; la navegació TFG/TFM es manté visible.
Respecta preferència de moviment reduït. Sense nous serveis, dependències o imatges externes.

Validació: 41 tests del Site, sintaxi JavaScript i revisió visual en navegador d'escriptori
(Campus i BeFirst, canvi de perfil estudiant/docent). Pendent revisió física a iPhone 15 Pro.
La còpia GitHub conserva els canvis funcionals de les PR apilades que encara no són al Site.
