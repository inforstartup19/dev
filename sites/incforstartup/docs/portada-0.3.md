`fd606078cc73c725fd349aec297fda49482808b4`.

sense hash o a `#entrada`. El clic entra al campus existent a `#inici`.

- Vuit esferes independents amb òrbites tridimensionals i ocultació davant/darrere.

- 1250 estrelles PC, 860 mòbil; viatge de 1050 ms.
- Una sola pantalla i lema «UNA IDEA POT CANVIAR-HO TOT», sense punt.
- Sense botó de pausa; respecta el moviment reduït del sistema. Esc acaba el viatge.
- Fallback si canvas falla; l'animació s'atura en ocultar la pestanya.

La marca del projecte continua sent IncForStartUp. Quelcom és el nom visible
aprovat per a la portada; el canvi global de marca encara és una proposta.

continua separada a #81 / #77, amb QA Safari/iOS i rendiment pendents a #55.

La sincronització no publica GitHub Pages ni desplega Azure.

proves de navegació heretades i comprovacions del repositori. El disseny s'ha
revisat al Site; no s'ha executat QA Safari/iOS real d'aquest port.
